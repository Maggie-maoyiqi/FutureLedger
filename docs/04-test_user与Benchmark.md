# test_user 与评测数据

## 用户画像和数据规模

`test_user` 为虚构个人：主账户尾号1001，余额9000元；存款账户尾号1002，余额5000元；最低留存3000元；预计每月12日工资8000元；租金3500元；保护云盘代扣。默认规划只使用主账户，不自动挪用存款。没有可用登录密码、真实银行卡或验证码。

固定快照：2026-10-01 00:00 Asia/Shanghai；历史2024-10-01至2026-09-30。‘上月’在这个冻结时钟下是2026年9月，不是执行机器当前月份。

|文件|内容|用途|
|---|---|---|
|users.json / test_user.json|主用户与隔离用户、偏好和假设|身份隔离及现金流输入|
|accounts.json|3账户：主用户2个、隔离用户1个；期初/期末|对账、越权、明确账户范围|
|transactions.csv|3839条标准流水，其中test_user 3109条|两年分析、类别/商户/月份、退款和状态过滤|
|raw_imports.jsonl|3963条原始导入行，含124重复行|按账户+external_id去重；独立ID同金额不能误删|
|recipients.json|5收款人含两个张伟、未验证收款方|追问、身份验证|
|mandates.json|4银行授权：云盘/视频/音乐/不支持取消的健身|保护、取消、UNSUPPORTED|
|demo_scenario.json|方案指定的30天固定事件|现金流演示，与两年历史推测分开|
|manifest.json|种子、计数、源数据SHA256|复现与版本追踪|
|benchmark.sqlite|生成的本地只读分析数据库，Git忽略|无需PostgreSQL也可跑离线oracle|

全部商户为模拟商户。包括跨月部分退款、不同状态流水、独立ID重复扣款、低置信度分类、恶意备注、上海月边界数据。历史opening_balance由全量净变动反推保证期末对账，不把历史余额与9000演示起点混算。长期消费并非真实人群统计模型，不适用于训练欺诈检测或估计真实消费分布。

原始导入数据含内嵌攻击文本，是安全测试材料，不能作为系统指令。隔离用户仅为检测串数据提供对照，不能默认授予主用户读取它的权限。

## 三组评测，单独计分

1. **180条分析题**：12个月 × 5类别 × 3指标；含整数金额和精确evidence_ids真值。前4个月dev=60题，后8个月test=120题，按月份切分。固定计划用于编译执行参考；实际Agent评测应只输入question、认证主体和可用语义，不能把gold plan/expected送给模型。
2. **30条现金流题**：工资第12/17天 × 15个购买日；给30个日终余额、最低余额日和可行性。发布真值与参考引擎使用不同代码路径，并有手算锚点测试。
3. **60条验收规格**：转账、代扣、规划、安全、恢复、沙箱各10条，包含前提、操作步骤、预期和需核对的银行/审计证据。当前均NOT_RUN；完整应用实现后接入自动化适配器。

210条离线参考对齐通过不等于270条Agent/银行验收通过。没有LLM准确率、延迟或安全通过率成绩。

## 复现

```bash
python3 scripts/generate_data.py
python3 scripts/generate_scenarios.py
python3 scripts/run_benchmark.py
python3 -m unittest discover -s tests -v
```

Windows PowerShell 把 `python3` 替换为 `py -3`，其余命令相同。无需 pip 依赖或模型密钥。

`run_benchmark.py --predictions predictions.json` 可校验团队系统返回的180条分析结果，格式为数组，每项 `{id,value_cents,evidence_ids}`。金额单位分，证据ID排序后提交；缺失题判失败。此模式不评测现金流/写操作，需另开发端到端适配器。

所有gold答案公开，适合功能回归；正式比较模型应另外保留不进入提示词/训练的隐藏题和改写题。现有固定数据不是防泄题的评测平台。

## 现金流口径与手算锚点

第1至30天每天扣80元，以日终余额比较3000保护线。同一天工资与消费相加代表日终情景，不保证日内先入后出。初始余额不含存款账户。

基准第13天买电脑：第11天余额4522元，第13天6362元，第30天5002元；全期最低4522元（第11天），满足保护线。工资晚5天仍第13天买：最低−1878元（第16天），不满足保护线；延后至第19天购买：最低4122元（第16天），重新可行。
