每项功能均为待实现范围；页面原型单独标注。

|---|---|---|---|

|银行基础|收款人验证、报价、即转、预约、取消未提交预约、查状态|给妈妈 500 → 验证尾号、确认、一次扣款；‘给张伟’ → 两候选追问|P0|
|安全执行|三级策略、逐笔确认、强验证、参数绑定、日额度预占、幂等、超时核验|两笔并发 600 → 累计触发红色；成功丢回包 → 待查证后成功且只扣一次|P0|

## 页面信息架构

1. `/` 银行总览：账户卡、可用余额、近期交易、三快捷入口；右侧 AI 助手。全局‘模拟银行’标识。
2. `/bills` 账单：月份与账户筛选、收入/支出/退款卡、类别分布、明细。点击统计可追溯 transaction_id。
3. `/subscriptions` 代扣：查询前范围确认；已确认授权与周期推测分别标注，保护云盘开关、取消入口和影响说明。
4. `/future` 未来账本：目标和硬约束、三情景按钮、余额曲线/保护线、最低值日期、逐日表格、方案比较。‘选择方案’之后才生成操作草稿。
5. `/tasks` 任务：待补参/待确认/待验证/预约/查证/终态列表，操作详情和用户接管。
6. `/settings` 偏好：最低余额、保护授权、通知与记忆删除；修改偏好不等于支付授权。
7. `/review` 评审：角色隔离，轨迹、规则、故障、复位；普通用户不可访问。

## 操作卡与状态

转账卡显示来源账户尾号、银行验证收款人及尾号、金额、币种、费用、执行日、风险级别、版本、有效期。按钮顺序：查看 → 明确确认 → 强验证（若需）→ 提交。验证独立表单不进入聊天或 LLM。

取消代扣卡显示授权 ID、商户、范围、保护状态、能否取消、生效时间；保护中的授权需先明确修改保护偏好，再创建新取消计划。请求失败或不支持保持‘未取消’。

SSE 断线显示‘连接中断，正在刷新’，用 GET 查询权威任务。待查证显示‘银行结果尚未确认’，只提供核验和接管；不能显示重试付款按钮。

## 可点击原型

`prototype/index.html` 展示上述信息架构，可切换总览/账单/代扣/未来账本/任务/偏好/评审。支持工资延迟和方案购买日变化，金额由页面整数分算法计算。它是离线设计原型，不是完成的前端，所有写按钮仅展示待确认说明。

桌面：左导航 200px，中间工作区，右助手 320px；手机：单列布局，横向导航，助手排在主内容后。深蓝与青绿为主色；风险用文字加颜色，不只靠红绿。
